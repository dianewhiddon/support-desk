# Changelog

## 1.0.0 — public release candidate

Standalone support requests, client conversations, private reply drafts and files, owner queue, delivery tracking, optional AI drafts and trusted-agent API.

Public-edition changes:

- MIT license, public contribution guidelines and complete setup, security, architecture and operations documentation.
- Shared neutral/gold light and dark theme, accessible queue tabs and POST sign-out.
- Hashed sign-in/session credentials, explicit link confirmation, atomic login limits, bounded request bodies and private response headers.
- Unified Office validation for client and owner uploads.
- Durable request/reply notification records and bounded retries within provider idempotency limits.
- Local fictional read-only demo, formatting and static analysis, and regression tests for release changes.

Derived from Diane Whiddon's standalone member edition at `84e8cb09abecd4a137674075aed48b6efbd5b5bd`. The public edition has its own release history; it does not replace or automatically update any installed member or private Portal deployment.
